# History and provenance

This original learning project was created in November 2026 with AI assistance.
Its fixture author dates and all committer dates follow an illustrative 2017 timeline.
These timestamps are simulated, not evidence of historical work, employment, or repository age.
Implementation and documentation author dates retain their actual values.

The current corpus contains 367 generated validation cases. Many are variations
of the same scenario; they are not independent features or evidence of years of development.
The supplied career roadmap is explicitly modeled. No employer accomplishments are asserted.
Original upstream histories or identities were not copied into this project.

## Repository presentation update

In November 2026 the README introduction was simplified and provenance moved here.
Fixture committer dates match their existing illustrative author dates. Setup snapshots
precede the first fixture; later documentation snapshots follow the latest prior fixture.
Code, tests, examples, fixture contents, author headers, and commit subjects were preserved.
Earlier message notes describing actual committer dates refer to the original build.

Feature, CLI, data, and documentation branches are shared development snapshots.
Shared branches do not multiply contribution credit. GitHub repository creation dates
and server-side activity timestamps are independent of these Git committer dates.
